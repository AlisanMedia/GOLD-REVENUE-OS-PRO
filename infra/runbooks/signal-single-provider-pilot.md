Recover only a capability-supported bounded range; otherwise keep OPEN/BLOCKED and request an approved alternative source. Never replay a begun send merely because its ACK was lost. Roll back code only to an explicitly approved compatible release; do not drop additive evidence tables or rewrite history. A restored database must be reconciled against external observations before resuming, with session revocation/replacement and source rights checked under separate authority.
