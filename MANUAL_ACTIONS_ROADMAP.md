# Gold Revenue OS — Manual Actions Roadmap (Phases 2–16)

**Last reviewed:** 2026-09-13  
**Operating rule:** staging and production accounts, keys, projects, bots and wallets must remain isolated. Secrets belong in provider secret stores and GitHub Environments; they must never be committed.

## Decision policy

- Create only the Phase 1 cloud-validation dependencies now: private GitHub repository, isolated Supabase staging project, and isolated Vercel staging project.
- Reserve the domain now if the final brand/domain is known; connect it only when the relevant public surface and email flows exist.
- Defer production infrastructure and usage-based providers until their phase entry gate. Early production provisioning creates cost and attack surface without creating revenue.
- Payment/access/state changes remain deterministic. AI services can propose an action but cannot directly mutate money, access or lifecycle state.
- Crypto payments remain provider-neutral. No provider is selected by this document and Telegram Stars is not the default.

## Cost reference snapshot

Prices change and must be rechecked at purchase time. As of the review date:

- GitHub Free private repositories include 2,000 standard-runner minutes/month; overage is metered: https://docs.github.com/en/billing/concepts/product-billing/github-actions
- Supabase Free is $0 with two active projects and no automatic backups; Pro starts at $25/month and includes daily backups retained seven days: https://supabase.com/pricing
- Vercel Hobby is $0 but is for personal/non-commercial use; Pro is $20/month before variable usage and is the relevant commercial tier: https://vercel.com/pricing
- Resend Free lists 3,000 emails/month; Pro lists $20/month for 50,000: https://resend.com/pricing
- Upstash Redis offers a free tier and usage/fixed paid plans; production HA is a separate cost tier: https://upstash.com/pricing/redis
